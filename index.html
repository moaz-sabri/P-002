What you can do

Tasks

Keep what you mean to do, with an optional estimate, planned date, subtasks, and running history.

Sessions

A timer for one piece of work. It stays on screen while you move around, and records time segments and events.

Reports

See where your time went: total time, session count, completed tasks, average session length, and active days.

Sync

Optional sync keeps devices aligned using encrypted records. The default is fully local.

Backup

Export and import your data with a password and owner code, with no lock-in.

Settings

Language, backup, device integration, wake lock, haptics, sound, and notification preferences.

How it works

  1. 1
    Create a task
    Give it an estimate, a planned date, and optional subtasks.
  2. 2
    Start a session
    Start a task session or a free session. The timer counts up and remains visible.
  3. 3
    Pause or finish
    The record moves through running → paused → completed/cancelled, with segments and events.
  4. 4
    Review results
    Reports derive figures on read from records that already exist.
  5. 5
    Sync if you want
    Sync is optional. Records are encrypted before they leave your device.

Architecture

Frontend (PWA, plain ES modules, no framework) ↓ Local storage (IndexedDB) ← primary store ↓ Application logic (services / domain / repositories) ↓ Optional sync → API (PHP single front controller) ↓ SQLite (PDO, ciphertext only)

Local-first

Your records live in this browser’s IndexedDB. The app works without a server, network, or account.

Derived, never stored

Reports and summary figures are computed on read. No total is persisted and no report cache drifts.

Privacy

No analytics, no telemetry, and no third-party requests. The only network calls are to your own origin, only when you enable sync. Sync is end-to-end encrypted with AES-256-GCM; the server stores ciphertext and holds no key.

No password recovery is provided by design. A lost password means a new space cannot be opened from a new device, while records already on your devices stay unaffected.

Run locally

npm ci npm run build # webpack --mode production → app/dist/ npm run dev # build, then PHP server on http://127.0.0.1:8080

Requires Node.js ≥ 20 and PHP ≥ 8.0 with pdo_sqlite and mbstring.
