# Tasker

Tasker تطبيق شخصي بسيط و local-first للمهام والجلسات الموقوتة.

## الميزات
- مهام مع تقديرات، وتواريخ مخططة، ومهام فرعية
- بدء جلسات مخصصة لمهام معينة أو جلسات حرة
- جلسة قيد التشغيل تبقى مرئية أثناء التنقل
- تقارير عن الوقت والجلسات والمهام
- تصدير/استيراد نسخة احتياطية
- مزامنة اختيارية ومشفرة

## التشغيل
```sh
npm ci
npm run build
npm run dev
```

## الخصوصية
بياناتك مخزنة locally، بدون تحليل أو تتبع، والمزامنة optional ومشفرة.
